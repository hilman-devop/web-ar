# AR Biologi SMA — Web Augmented Reality

> Media pembelajaran Biologi SMA kelas XI berbasis WebAR untuk mengeksplorasi sistem pernapasan dan sistem koordinasi manusia.

**Stack:** HTML5 · JavaScript · AR.js · A-Frame

![Preview](https://raw.githubusercontent.com/hilman-devop/web-ar/main/image/image.png)

## Ringkasan

Media pembelajaran Biologi SMA kelas XI berbasis WebAR untuk mengeksplorasi sistem pernapasan dan sistem koordinasi manusia.

## Fitur utama

- Landing page responsif
- Modul AR-BREATH
- Modul AR-COORDINATION
- Model 3D dan marker edukasi
- Akses melalui browser tanpa aplikasi native

## Menjalankan secara lokal

~~~bash
python -m http.server 8080
~~~

## Keamanan dan batasan

Akses kamera membutuhkan browser yang mendukung permission camera dan konteks aman saat diperlukan.

Jangan commit API key, password, token, session ID, data pribadi, atau credential deployment.
